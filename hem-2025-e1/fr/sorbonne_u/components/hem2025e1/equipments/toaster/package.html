Toaster equipment component for HEM.

The package defines an uncontrollable toaster component for the household energy management (HEM) system. The toaster is a high-power appliance that cannot be controlled by the energy manager - it is activated only by user action.

This appliance creates unpredictable power consumption peaks that the HEM must handle by adjusting other controllable appliances (Fan, Refrigerator, WashingMachine).

Package structure
ToasterImplementationIInternal implementation interface with ToasterState enum
ToasterUserCIUser-facing component interface (CI)
ToasterThe toaster component implementation
ToasterTesterA component that tests the toaster through its CI
CVMUnitTestA CVM to execute the unit tests

States

  • OFF: 0W - Lever is up, toaster idle
  • TOASTING: 1000W - Lever is down, heating elements active

Behavior

  • pushDown(): Start toasting (activates heating elements)
  • pullUp(): Stop toasting and eject toast
  • Automatic stop: After 2 minutes, the toaster automatically pulls up
