Refrigerator equipment component for HEM.

The package defines a non-programmable refrigerator component for the household energy management (HEM) system. The refrigerator has thermostat control and a suspendable compressor for energy management.

Package structure
RefrigeratorImplementationIInternal implementation interface with RefrigeratorState enum
RefrigeratorUserCIUser-facing component interface (CI)
RefrigeratorThe refrigerator component implementation
RefrigeratorTesterA component that tests the refrigerator through its CI
CVMUnitTestA CVM to execute the unit tests

States

  • OFF: 0W - Refrigerator is powered off
  • ON: 150W - Compressor running
  • SUSPENDED: 10W - Compressor suspended by HEM
