Fan equipment component for HEM.

The package defines a simple fan component for the household energy management (HEM) system. The fan has four states: OFF, LOW, MEDIUM, and HIGH, each with different power consumption levels.

Package structure
FanImplementationIInternal implementation interface with FanState enum
FanUserCIUser-facing component interface (CI)
FanThe fan component implementation
FanTesterA component that tests the fan through its CI
CVMUnitTestA CVM to execute the unit tests

Power Levels

  • OFF: 0W
  • LOW: 50W
  • MEDIUM: 100W
  • HIGH: 150W
