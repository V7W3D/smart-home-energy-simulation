WashingMachine equipment component for HEM.

The package defines a programmable washing machine component for the household energy management (HEM) system. The washing machine supports multiple wash programs with different durations and power consumptions, as well as deferred start scheduling.

Package structure
WashingMachineImplementationIInternal implementation interface with state and program enums
WashingMachineUserCIUser-facing component interface (CI)
WashingMachineThe washing machine component implementation
WashingMachineTesterA component that tests the washing machine through its CI
CVMUnitTestA CVM to execute the unit tests

States

  • OFF: Washing machine is powered off
  • IDLE: Powered on, waiting for program selection or start
  • SCHEDULED: A deferred start has been programmed
  • RUNNING: A wash cycle is in progress
  • SUSPENDED: The cycle is temporarily paused (by HEM)
