Connection classes for the WashingMachine component.

This package defines the inbound port, outbound port, and connector for the WashingMachine component interface.

Package structure
WashingMachineInboundPortInbound port implementing WashingMachineUserCI
WashingMachineOutboundPortOutbound port implementing WashingMachineUserCI
